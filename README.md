# Logic Programming in C 🖥️

Welcome! This repository contains a collection of exercises and projects developed in the C programming language, focused on strengthening programming logic and mastery of fundamental data structures.

## 📂 Repository Structure

The content is organized by levels of complexity to facilitate learning:

* *01-Fundamentals:* Basic concepts, data types, and simple operations.

* *02-Control Structures:* Implementation of conditionals (if/else, switch) and loops (for, while).

* *03-Functions, Arrays, and Pointers:* Code modularization and memory management.

* *04-Final Projects:* Integrated applications with complex logic.

 ## 🛠️ Technologies Used
* *Language:* C
* *Compiler:* GCC (MinGW for Windows)
* *Editor:* Visual Studio Code

## 🚀 How to Run the Exercises
1. Clone the repository:

git clone https://github.com
2. Navigate to the exercise folder.

3. Compile the file:

gcc filename.c -o program

4. Run:
   
./program
